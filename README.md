# GemProbe

輕量、即時的 Gemini API 模型連通性探測與對話測試工作台。

GemProbe 是一個零依賴、純前端的靜態工具。只需輸入您的 Google Gemini API Key，系統會自動查詢帳號支援的模型列表，逐一發送測試請求並過濾無效或報錯的模型，最終呈現確認可用的模型清單，並可立即選取模型進行多輪對話測試。

---

## 核心特色

- **精準可用性檢測**：自動篩選支援文字生成（`generateContent`）的模型，逐一發送 ping 測試，僅列出正常回傳成功的模型，自動略過報錯、無權限或配額耗盡的模型。
- **左右分欄工作台**：
  - 左側：即時更新的可用模型清單，點選即可快速切換目標模型。
  - 右側：多輪對話測試視窗，支援上下文記憶與清空功能。
- **極簡體驗與自動收合**：
  - 輸入 API Key 開始測試後，輸入框自動折疊為遮蔽狀態（Masked Key）。
  - 檢測完成後，進度面板自動隱藏，最大化工作區視野。
  - 提供右上角隨時開啟「更換 Key」與「清除」功能。
- **隱私與安全**：
  - 純客戶端執行（Client-side Only）：無後端伺服器，API Key 僅由瀏覽器端直接連線至 Google 官方端點，無資料外洩疑慮。
  - 零依賴架構：單一 HTML 檔案即可執行，無需建置工具或外部套件庫。

## 快速開始

### 1. 下載或建立檔案
將專案程式碼儲存為 `index.html`。

### 2. 啟動方式（二選一）
- **直接開啟**：在電腦上雙擊 `index.html`，以任一現代瀏覽器開啟即可。
- **本地伺服器（推薦）**：透過 Python 本地伺服器開啟：
  ```bash
  python -m http.server 8000
  ```
  在瀏覽器輸入 `http://localhost:8000` 即可使用。

## 使用說明

1. **輸入 Key**：在頁面上方貼入 Gemini API Key，點擊「儲存並測試可用模型」。
2. **自動探測**：
   - 輸入框自動收合並顯示測試進度條。
   - 系統依序發送測試訊號至所有候選文字模型。
3. **對話測試**：
   - 檢測完成後進度面板自動關閉。
   - 點選左側列表任一標示「可用」的模型。
   - 在右側對話輸入框鍵入文字，即可測試該模型的回應內容與語意理解。
4. **更換或清除 Key**：
   - 隨時點擊右上角的「Key 管理」按鈕展開面板。
   - 點擊「更換 Key」可重新輸入新密鑰，或點擊「清除」重置為初始狀態。

## 技術規格

- **前端技術**：HTML5 / CSS3（Flexbox、CSS Grid） / Vanilla JavaScript (ES6+ async/await)
- **API 介接端點**：
  - `GET /v1beta/models`（取得模型列表）
  - `POST /v1beta/{model=models/*}:generateContent`（通訊檢測與交談發送）
